Serializers ​

MetaTypeSerializer ​

python
class MetaTypeSerializer(serializers.ModelSerializer):
    class Meta:
        model = MetaType
        fields = "__all__"

Standard DRF ModelSerializer for MetaType. The schema field serializes as a JSON list of MetaTypeFieldDef dicts.

MetaInstanceSerializer ​

python
class MetaInstanceSerializer(serializers.ModelSerializer):
    data = serializers.JSONField()

    class Meta:
        model = MetaInstance
        fields = "__all__"

Validation ​

The serializer resolves the meta_type (from the payload on create, or from the existing instance on update) and validates data against the runtime Pydantic model:

  • If meta_type is missing and no existing instance is available, a validation error is raised.
  • If data does not conform to the schema, the Pydantic error is forwarded as a DRF ValidationError on the data field.
  • Valid data is normalized via model_dump(mode="json") before saving.
