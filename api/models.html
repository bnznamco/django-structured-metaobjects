MetaType ​

python
class MetaType(models.Model):
    name = models.CharField(max_length=200)
    schema = StructuredJSONField(default=list, schema=MetaTypeFieldDef)
    compiled_at = models.DateTimeField(auto_now=True)

A user-defined "type" describing the shape of a MetaInstance. The schema field is a list of MetaTypeFieldDef rows.

Methods ​

  • get_pydantic_model() — Returns the compiled Pydantic model class for this type (cached).
  • get_json_schema() — Returns the JSON Schema dict for this type.
  • save() — Saves and invalidates the compiler cache for this type.

MetaInstance ​

python
class MetaInstance(models.Model):
    meta_type = models.ForeignKey(MetaType, on_delete=models.PROTECT)
    data = models.JSONField(default=dict, blank=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

Concrete entry whose shape is dictated by its referenced MetaType.

Properties ​

  • obj — Returns data parsed into the runtime Pydantic model. The result is cached on the instance and invalidated when data changes. FK and queryset fields lazily resolve to real Django objects.

Methods ​

  • clean() — Validates data against the schema and normalizes it (e.g., coerces "5" → 5 for integer fields).
